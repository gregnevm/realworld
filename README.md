# RealWorld

Survival-MMORPG із симуляційною глибиною RimWorld на **картах зі справжньої географії** (OpenStreetMap / GPS). Один глибоко симульований персонаж, persistent-світ, логістика конвоями між реальними локаціями, рейди інших гравців.

> **Стейдж:** Фаза 0 — одиночний граний вертикальний зріз. Деталі дизайну — у `GDD_BOOK/`. Контекст для AI-агентів — у [`AGENTS.md`](AGENTS.md).

## Структура
| Тека | Що це |
|---|---|
| `game/` | Граний веб-прототип (HTML5 Canvas, vanilla JS, без збірки) |
| `godot/` | Порт у Godot 4.7 (GDScript): AStarGrid2D, детермінований worldgen, headless-тести |
| `GDD_BOOK/` | Інтерактивний Game Design Document (джерело істини — `gdd.json`) |
| `tests/` | Тести детермінованого ядра симуляції (`node --test`) |
| `specs/` | Специфікації фіч (цикл Specify → Plan → Tasks → Implement) |

## Запуск
```bash
# гра
cd game && python -m http.server 8765      # → http://localhost:8765

# тести
npm test                                    # node --test "tests/**/*.test.js"

# GDD
python "<gdd_build>/scripts/serve.py" GDD_BOOK

# Godot-версія (4.7): тести headless / запуск
<godot_console.exe> --headless --path godot -s res://tests/run_tests.gd
<godot.exe> --path godot          # відкрити гру у вікні
```

## Як грати
Клік по землі — йти - клік по 🌲/🪨/🫐/руїні — добути - неси на 📦 склад - нижня панель (або `1`–`7`) — будуй - 🗗 / `M` — конвої-логістика - `WASD` — рух - `H` — довідка. Рейди приходять циклічно (у MMO — інші гравці).

## Технічні принципи
- **No-build:** браузер виконує файли як є; глобальний неймспейс `RW`, фіксований порядок підключення скриптів (див. `AGENTS.md`).
- **Детермінізм:** карта повністю відтворювана з `lat/lon` (seeded RNG); реальна геометрія OSM накладається зверху, з процедурним fallback.
- **Тестопридатність:** чиста логіка симуляції тримається без залежності від DOM — той самий код стане спільним ядром клієнта й сервера у Фазі 1.

## Roadmap (коротко)
Фаза 0 — цей зріз - Фаза 1 — тонкий authoritative-сервер (Node) + 2–3 гравці на одній карті, спільне sim-ядро - далі — масштаб, asset-пайплайн, економіка. Повний план — в історії CTO-сесії.
