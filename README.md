# RealWorld

Survival-MMORPG із симуляційною глибиною RimWorld на **картах зі справжньої географії** (OpenStreetMap / GPS). Один глибоко симульований персонаж, persistent-світ, логістика конвоями між реальними локаціями, рейди інших гравців.

> **Стейдж:** Фаза 0 — одиночний граний вертикальний зріз. Деталі дизайну — у `GDD_BOOK/`. Контекст для AI-агентів — у [`AGENTS.md`](AGENTS.md).

## Структура
| Тека | Що це |
|---|---|
| `game/` | Граний веб-прототип (HTML5 Canvas, vanilla JS, без збірки) |
| `godot/` | Порт у Godot 4.7 (GDScript): AStarGrid2D, детермінований worldgen, headless-тести |
| `godot/content/` | Дерево контенту — `catalog.json`: 335 def (ресурси/дослідження/будівлі/рецепти/предмети, від неоліту до космічного корабля), валідоване на досяжність від сирих ресурсів. Дерево досліджень **проходиться** пайплайном прогресії (`kernel/progression.gd`, spec 0007). Довідник — [`docs/catalog.md`](docs/catalog.md) |
| `GDD_BOOK/` | Інтерактивний Game Design Document (джерело істини — `gdd.json`) |
| `tests/` | Тести детермінованого ядра симуляції + валідація дерева контенту (`node --test`) |
| `specs/` | Специфікації фіч (цикл Specify → Plan → Tasks → Implement) |

## Запуск
```bash
# гра
cd game && python -m http.server 8765      # → http://localhost:8765

# тести
npm test                                    # node --test "tests/**/*.test.js"
npm run lint                                # контракт порядку скриптів, strict-IIFE, без Math.random у симі
npm run smoke                               # Playwright-прохід реальної гри в headless Chromium (скриншоти → build/smoke)

# GDD
python "<gdd_build>/scripts/serve.py" GDD_BOOK

# Godot-версія (4.7): тести headless / запуск
<godot_console.exe> --headless --path godot -s res://tests/run_tests.gd
<godot.exe> --path godot          # відкрити гру у вікні
```

## Як грати
Клік по землі — йти · клік по 🌲/🪨/🫐/руїні — добути · неси на 📦 склад · нижня панель або `1`–`0` — будуй (стіни/двері/підлогу/грядки/пастки можна **тягнути лінією**) · клік по своїй будівлі — вибрати (`F` полагодити, `Del` розібрати) · наведення курсора показує, що під ним · мінімапа (клік — іти) · колесо / `+` `−` — зум · `Пробіл` — пауза, `Tab` — швидкість · `M` конвої-логістика · `R` дослідження · `L` журнал · `H` довідка · `Esc` — скасувати / меню · `WASD` — ручний рух. Рейди приходять циклічно (у MMO — інші гравці); червоні стрілки на краю екрана показують, звідки.

## Технічні принципи
- **No-build:** браузер виконує файли як є; глобальний неймспейс `RW`, фіксований порядок підключення скриптів (див. `AGENTS.md`).
- **Детермінізм:** карта І геймплей повністю відтворювані з `lat/lon` (seeded RNG: worldgen + рейди/лут/засідки через `G.rng`, стан зберігається в сейві); реальна геометрія OSM накладається зверху, з процедурним fallback.
- **Тестопридатність:** чиста логіка симуляції тримається без залежності від DOM — той самий код стане спільним ядром клієнта й сервера у Фазі 1.

## Roadmap (коротко)
Фаза 0 — цей зріз - Фаза 1 — тонкий authoritative-сервер на **Godot headless** (spec 0006, option A; Node — fallback лише за виміряної нестачі хостингу) + 2–3 гравці на одній карті, спільне sim-ядро - далі — масштаб, asset-пайплайн, економіка. Повний план — в історії CTO-сесії.
