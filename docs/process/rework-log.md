# Журнал правок після агента (метрика P10)

> Перше, що варто вимірювати в ШІ-розробці: **скільки й чого людина переробляє після агентної задачі**. Якщо більшість правок у механіках, керуванні, UI — посилюємо ворота G0–G1 і плейтест (G5). Якщо в коді — тести й закріплення API. `npm run process` рахує це з таблиці нижче.

**Як записувати:** один рядок на правку власника, плейтесту або незалежного ока, що змінила результат агентної задачі **після** того, як агент сказав «готово». Категорія — одна з: `mechanic` · `control` · `ui` · `text` · `balance` · `scope` · `code` · `art`.
