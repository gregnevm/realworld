# Набір для плейтесту (G5) — картка гравця + бланк спостерігача

Протокол і метрики — `docs/process/playtest.md`. Цей файл — те, що роздруковується/відкривається на сесії. Журнал сесії (з датою в імені) створюється ПІСЛЯ неї за шаблоном §3 протоколу.

## 0. Білд (зафіксуй у журналі)

| Канал | Артефакт | Звідки |
|---|---|---|
| **APK** (лише телефон, OD-124) | `android-apk` останньої збірки main | реліз [`main-latest`](https://github.com/gregnevm/realworld/releases/tag/main-latest) → APK |

- Яка це збірка — видно в грі: ☰ → нижній рядок «Збірка v… · #запуск · sha · дата». Запиши sha в журнал.
- Артефакти GitHub скачуються лише з акаунту з доступом до репо; для гравців — роздай APK файлом/посиланням сам.
- Місто/seed: одна й та сама висадка для всіх гравців, щоб порівнювати.
- **Секундомір не потрібен (G4, REQ-0010-42 / REQ-0012-52).** Збірка сама міряє «старт застосунку → посадка» і «посадка → перша дія гравця» (збір або споруда). Після гравця: ☰ → ⚙ Налаштування → унизу рядки «⏱ посадка за … · перша дія (…) за … ✓/✗» (останні 5 висадок, найновіша зверху). Перепиши їх у бланк.
- Між гравцями: ⚙ → «Нова гра» і одразу віддай телефон — відлік наступного гравця йде від появи меню (у рядку буде «від меню», а не «від старту застосунку»); попередні виміри лишаються в списку.

## 1. Картка гравця (читає гравець; більше нічого не пояснюй)

> Це нова гра. Інструкцій не буде — просто грай і думай вголос. Я мовчатиму й нотуватиму; питати «як це зробити?» можна, але я не відповім — це нормально, питання мені корисні.
>
> 1. **Висадись** у грі.
> 2. **Розпали вогонь.**
> 3. **Пережи ніч.**
> 4. **Скрафти й постав будівлю.**
> 5. **Знайди свою торбу після смерті.** *(якщо не помер — спостерігач скаже «тепер ти загинув»; див. нижче)*

Примітка спостерігачу: задачі оголошувати **по одній**, коли попередня виконана або гравець здався. Якщо гравець не помирає за 30 хв — після задач 1–4 запусти смерть вручну (меню/debug) і лише потім читай задачу 5; запиши, що смерть була підстроєна.

## 3. Після сесії

Надиктуй (голосом можна) нотатки одним повідомленням на кожного гравця — агент:
1. створить `docs/process/playtests/YYYY-MM-DD-<коротко>.md` за шаблоном;
2. зробить тріаж: `fix` / `OD-n` / `scope` / `noise`; повторюване між ≥2 людьми — ніколи `noise`;
3. допише `docs/process/rework-log.md`, відкриє PR.

Мінімум для статистики: **3 гравці** (оптимум 5–7). Один гравець — це ще не плейтест, а розвідка.
