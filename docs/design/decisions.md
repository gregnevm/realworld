# Реєстр рішень власника (OD)

> Одне місце для всього, що вирішує **лише власник** (P1): стовпи, scope, модель вводу, баланс, політика ШІ-арту, великі рефактори. Агент **додає** відкрите питання з варіантами; **закриває** — тільки власник (статус `decided`, дата, вибір).
> ID ніколи не перевикористовуються. Статуси: `open` · `decided` · `superseded`. `npm run process` показує відкриті на старті кожної сесії.
