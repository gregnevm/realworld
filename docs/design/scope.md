# Scope Фази 0

> **Фокус фази:** одиночний вертикальний зріз проходить G4 (перші 60 с) і G5 (люди) на телефоні. Усе, що не наближає до цього, — заморожено.
> **Правило (P7):** система живе в розвитку лише з вердиктом власника `розвивати`. `заморозити` = код лишається, тести зелені, але система не росте, не отримує UI й арту. `вирізати` = прибрати з гри (окремим PR). Пропозиції — агента; останню колонку заповнює лише власник (OD-3).
