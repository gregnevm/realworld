# Godot: view-шар (12 правил), гочі, тести, збірки

> Правила UI, GDScript-гочі, перелік сьютів, скриншоти, APK, web-експорт. Виділено з `AGENTS.md` (OD-8, F6). Тримай актуальним разом із кодом.

- **12 правил view-шару (spec 0005 §1, примусові через `run_ui_tests.gd`):** R1 односторонній потік (sim не імпортує ui) · R2 build-once-then-bind (без ребілду панелей) · R3 стилі лише через `Tokens`/`Theme` (жодних inline `Color(`/`StyleBoxFlat` поза `tokens.gd`/`theme.gd`) · R4 контролер не називає жодної механіки · R5 кожне число з `explain()` · R6 просторовий стан = `Overlay`, не список координат · R7 resize-safe анкери лише через `Widget.pin_*` · R8 слайси — тільки value-data · R9 sim-команди лише в роутері · R10 фідбек — один адаптер · R11 enum+іконка+число (не лише колір) · R12 keyboard-first + видимий детермінізм.
- **GDScript-гочі (обов'язково):** `:=` не виводить тип із `Variant` (доступ до поля `Dictionary`, `abs()`, нетипізований метод) → явний `: Type` або `absf/absi`; JSON round-trip перетворює `int→float`; `RefCounted` не збирає цикли → чисти крос-рефи в `_exit_tree()`, а Thing↔Comp рвуться через `Thing.detach()` / `CatalogSim.dispose()`/`dispose_shared()` (сим прунить destroyed-Things у `tick()`); лише seeded `RandomNumberGenerator`; **інклас+preload** (жодного top-level `class_name`, жодних autoload); анкери resize-safe. Інклас з іменем `Panel` **шедовить** нативний `Panel` — базу названо `Base`. **Статична типізація примусова:** кожен `var` у продуктових скриптах типізований (nullable/гетерогенні — явний `: Variant`); tripwire в `run_tests.gd` валить CI за нетипізоване оголошення; `untyped_declaration=1` у `project.godot` підсвічує в редакторі (headless аналайзер-ворнінги НЕ друкує — не покладайся).
- **Тести (headless):** `test.cmd` у корені ганяє сьюти — `run_tests` (440, вкл. грабельність: `_t_playable_opening`/`_t_auto_haul`/`_t_goals_chain`/`_t_save_continue`/`_t_death_epitaph`, tripwires «жодного глобального randf/randi», «жодного годинника в sim» (`_t_no_wallclock_in_sim`, spec 0012 REQ-10 — зеркало `npm run lint`), «жодного нетипізованого var» і «жодного stock[...] поза швом», детермінізм рейдів + патрулів, контент-пак, research-ворота + валідація gate-id проти каталогу, персистенс use_catalog, локалізоване здоров'я: `_t_hero_health`/`_t_cold_exposure`/`_t_deprivation_live`/`_t_health_persistence`, живий каталог: `_t_catalog_live`, мережа: `_t_power_live`, ферми: `_t_farming_live`, режисер: `_t_director_live`), `run_kernel_tests` (254, вкл. deprivation + fine-dday регресії), `run_catalog_tests` (98, вкл. lifecycle-sweep і форму таблиці `capsule_levels` spec 0010), `run_progression_tests` (42), `run_ui_tests` (277, spec 0005 + touch-кадр + граматика world_input (вкл. set_crop-клік, пауза/швидкість, drag-ряди) + §3-hotkey-контракт + live-слайс каталогу + інспектор/фідбек-монтаж/топ-бар/цілі + «одна правда» нічної тіні й теплової карти), `run_determinism_tests` (7, spec 0006 §4: `Persistence.world_hash` — twin-інстанції з одним seed/командами → ідентичний full-world хеш; + spec 0010: ON-twin капсули з фіксованим `set_clock`; CI додатково ганяє сьют двічі як два OS-процеси і порівнює обидва рядки `WORLD_HASH_FINAL=` (OFF) і `WORLD_HASH_CAPSULE=` (ON) — крос-процесний анти-десинк tripwire), `run_snapshot_tests` (9, spec 0006 §8.3: дельта-кодек — wire-fidelity 600/600 тіків через реальний JSON round-trip + замір payload), `run_command_tests` (34, spec 0006 plan §4: конверт — таблиця відмов, канонічний порядок незалежний від прибуття, ідемпотентність, tripwire «wire-словник ⊆ input_verbs.gd»), `run_rejoin_tests` (18, spec 0006 plan §5: resume-payload хеш-точний (у т.ч. через дріт і з пішаком «у дії»), сейв-формат сам по собі — НІ, цілісність hash-ланцюга, resume seq), `run_capsule_tests` (109, spec 0010, хвиля S0: **«прапор OFF == код до спеки»** — REQ-0010-01/02/60/61 проти фікстури `godot/tests/fixtures/off_baseline.json`, знятої з НЕзміненого бейслайну dev-скриптом `tests/capture_baseline.gd` (поза CI; заголовок: `baseline_commit`, `platform`, `godot_version`); сценарії — `tests/off_scenarios.gd` (одна копія для захоплення й сьютів): twin ambient (WORLD_HASH_FINAL літералом), `_flat_sim`, use_inventory/use_catalog ON, power+farm, форсований рейд на обнесений мурами склад, `Director.apply`/гейт грейс-днів/53 доби живого режисера, патруль+турель, смерть→`respawn_new_pawn` (стандартна/інвентарна/в іншому регіоні), demolish/`base_center`, радіуси stash/take/зв'язку/верстака, крафт, денна капсула на переході доби, `try_launch_capsule`, `travel_to`, OSM-релокація, сідований fuzz verbs, схема запису/сейва та **три старі сейви бейслайну** (stock/inventory/catalog) у фікстурі; плюс tripwire «жодного Time.*/OS.get_*time* у sim-шляху» (REQ-0010-92); **рядки, яких не бачить жоден хеш** (`sim.messages`/`flash_msg`/підписи панелі — «view, not sim», M5/F10): фід висадки/подорожі/«Продовжено» (`Session.start` БЕЗ `messages.clear()`), флеш-підказки з клавішею «(4)» і відмови будівництва, підписи/кнопки/інтенти/відмови `CapsulePanel` (на hand-made vm і на реальному знімку сесії) — сценарії `session_feed`/`flash_hints`/`capsule_panel_off`, пінені і фікстурою (число °C у підказках маскується в portable, точне — у numeric), і ЛІТЕРАЛАМИ в `_t_off_baseline_texts` (перезнята фікстура не може «благословити» зміну формулювання); число сценаріїв = літерал `SCENARIO_COUNT`. Два яруси пінів: `portable` (тексти, клітинки, множини ключів — на ВСІХ платформах) і `numeric` (world_hash/float після тіків — через libm `cos()` лише на платформі захоплення: та сама платформа → жорстке порівняння, **інша платформа в CI → FAIL**, інша локально → гучний `[SKIP]` + банер WARN, ніколи тихий pass). Фікстуру перезнімають лише на бейслайн-коміті навмисним рішенням: `godot --headless --path godot -s res://tests/capture_baseline.gd -- commit=$(git rev-parse HEAD) write`; нове `_t_*` від хвиль 0010 дописується під блоком `_t_off_*`, а `_t_off_*` лишаються зеленими після КОЖНОЇ хвилі (D4). Float у фікстурі порівнюються з допуском 1e-9 (JSON-парсер Godot помиляється на 1 ulp для ~9% double), рядки/цілі/bool — точно), `run_realtime_tests` (66, spec 0012, S0: REQ-0012-1/2/3/4/81 — та сама фікстура: хеш/рядок `save_game` (sha256) байт-у-байт при `use_realtime=OFF`, множина ключів save/запису/runtime, `SAVE_VERSION==1`, `day_len=150` + швидкості ×1–×3/пауза + 10 цілей + константи голоду/сну, денна капсула 0002 без змін, старий сейв вантажиться OFF і не мігрує), `run_net_spike` (17, spec 0006 plan §2 end-to-end: оркестратор спавнить **1 authoritative headless-сервер + 2 клієнти-процеси** (`tests/net/`) через реальний localhost-WebSocket; lockstep із серверним echo-розкладом команд; `world_hash` мусить збігтися на всіх трьох — інтеграційний, у CI окремим степом поза сьют-лупом; транспорт Phase 1 = **WebSocket** (web-експорт без UDP, TCP-порядок спрощує командний конверт)), `run_smoke` (8). Окремо `run_perf` — **інформаційна** перф-проба поза CI-гейтом (worldgen + вартість тіка на n=56/112/224; базлайн 2026-07: тік ~15–28 µs ≈0.2% бюджету 60fps, worldgen 18→269 ms — вузьке місце на великих картах worldgen/рендер, не сим; headless не міряє custom-draw рендер); `run_capsule_balance` — теж **інформаційний** (економічний бот Основної капсули, spec 0010 W2a: дохід/кінцевий запас нод/пропозиція вартості-радіуса-бафів-`core_hp` і MATCH/DIFF проти `capsule_levels` у каталозі; `godot --headless --path godot -s res://tests/run_capsule_balance.gd`, ~20 с). Усі сьюти виходять **без ObjectDB-ліків** (нові Things у тестах — detach/dispose в кінці тесту). CI (`godot.yml`) грепає leak-warning у кожному сьюті + окремий job **gdlint** (gdtoolkit 4.x; конфіг `gdlintrc` у корені кодифікує конвенції — RimWorld-канонні `Sub_Class` імена, max-line 200, без class-definitions-order; заморожений `scripts/main.gd` і `godot/tests/` поза скоупом). Локальний гейт — `.pre-commit-config.yaml` (`pip install pre-commit && pre-commit install`); gdformat свідомо не увімкнений (масовий реформат — окремий крок). Плюс `npm test` (Node) ганяє детерміноване sim-ядро + валідацію `catalog.json`. Годо-екзе: Windows — `%LOCALAPPDATA%\GodotPortable\Godot_v4.7-stable_win64[_console].exe`; Linux/CI — офіційний `Godot_v4.7-stable_linux.x86_64` (реліз-zip із GitHub, як у `godot.yml`). Приклад: `Godot_console.exe --headless --path godot -s res://tests/run_ui_tests.gd`.
- **Скриншот нового HUD:** `Godot_console.exe --path godot res://newhud.tscn -- newhud shot` (віконно, не headless) → `godot/newhud_shot.png`. Телефонний вигляд: `--resolution 1600x720 ... -- touch scale=1.68`.
- **Android APK:** `Godot_console.exe --headless --path godot --export-release "Android" build/android/RealWorld.apk` (потрібні Android-шаблони 4.7, Android SDK build-tools з `apksigner`, JDK 17+, release-ключ через `GODOT_ANDROID_KEYSTORE_RELEASE_PATH/USER/PASSWORD`). CI робить це сам (job `godot-android-build`, артефакт `android-apk`).
- **Web-експорт (клік-і-грай):** `Godot_console.exe --headless --path godot --export-release "Web" build/web/index.html` → `godot/build/web/` (gitignored); на свіжому checkout спершу `--import`. Пресет `godot/export_presets.cfg`: **threads OFF** (без COOP/COEP — працює на будь-якому статичному хостингу; рендер веб-дефолтний gl_compatibility). **CI білдить сам:** job `godot-web-build` у `godot.yml` — артефакт `web-build` (готовий клік-і-грай зі README.txt) з кожного пушу; темплейти кешуються між ранами. Шаблони локально: Windows — `%APPDATA%\Godot\export_templates\4.7.stable\web_*.zip` (тягнуться частково з 1.28ГБ tpz HTTP-Range-скриптом — не качай весь); Linux — `~/.local/share/godot/export_templates/4.7.stable/` (range-запити до GitHub-CDN ненадійні — качай tpz цілком транзитно і бери лише `templates/web_*`, як робить CI-job). Локальне прев'ю: dev-сервер `godot-web` (порт 8792, `.claude/launch.json`); ГОЧА: прихована вкладка прев'ю заморожує rAF → одно-тредовий web-білд Godot не рендерить і canvas лишається 0×0 — верифікуй у ВИДИМІЙ вкладці (claude-in-chrome). **Емодзі-іконки у веб-білді ПРАЦЮЮТЬ:** монохромний NotoEmoji (OFL, `godot/assets/fonts/`) підвішений фолбеком через `theme.gd` — `Theme.default_font` = FontVariation(base=вбудований, fallbacks=[NotoEmoji]) + `ThemeDB.fallback_font` для custom-draw; сам лише `ThemeDB.fallback_font` НЕ працює (дефолтна тема Godot несе власний шрифт і перехоплює lookup — десктоп маскує це системними шрифтами). Завантаження шрифту двошляхове: `ResourceLoader` (експорт пакує ttf як imported-ресурс заремапом — сирого шляху в PCK нема) АБО `FileAccess`+`load_dynamic_font` (свіжий checkout / headless-тести без import-кешу).
