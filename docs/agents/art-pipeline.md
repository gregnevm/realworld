# Арт-пайплайн gen-art (Nano Banana)

> Повний опис пайплайну й стану арту. Виділено з `AGENTS.md` (OD-8, F6). Тримай актуальним разом із кодом.

- **Що:** концептуально-консистентна генерація спрайтів/акторів/іконок/тайлів/UI через Gemini image API (дефолт `gemini-nano-banana-2.1` — міграцію з `gemini-2.5-flash-image` виконано 2026-11-04: якорі й усі раніше затверджені асети перегенеровано, тож весь арт з однієї моделі; старий id Google вимикає 2027-03-15. Не міняй модель посеред серії; Pro — `--model gemini-3-pro-image`; `-preview` id вимкнені, CLI їх відхиляє). Скіл — `.claude/skills/gen-art/SKILL.md` (/gen-art).
- **Лор арту:** ШІ-постапокаліпсис (рішення власника 2026-11-04) — машини, що керували світом, повстали; патрульні роботи досі ходять маршрутами, виживальники ховаються від сенсорів і розбирають машинні туші на брухт/компоненти; пізні тіри = реверс-інжиніринг машинних технологій. Живе в `art/style.md` WORLD і `eraOf`. GDD («Світ і сеттинг») досі каже «м'який колапс» — не узгоджено.
- **Консистентність = 4 шари:** `art/style.md` (біблія, префікс КОЖНОГО промпту) + рамка kind (`KINDS` у `tools/art/lib.mjs`: ракурс/фон/кадр/розмір) + епоха з research-tier (`eraOf`) + ≤3 затверджені якорі `art/refs/*.png` як image-input (затверджено `ref_world`, `ref_ground`). Снеп до `art/palette.json` — ОПЦІЙНИЙ (`--palette`/`palette: true`): на painterly-рендерах він постеризує.
- **Постобробка (`tools/art/post.py`, Pillow + numpy):** ГОЧА першого живого батчу — модель НЕ малює `#FF00FF`: muted-біблія тягне «магенту» до ~(190,50,112)…(219,40,147), плюс віньєтка й падаюча тінь того ж відтінку. Тому keying АДАПТИВНИЙ: фон оцінюється з краю, піксель = фон за ХРОМАТИЧНІСТЮ (світліший → alpha 0, темніший → м'яка чорна тінь ≤0.5), обідок 3 px — alpha з RGB-відстані + un-mix `(c-(1-a)·bg)/a`, смуга 24 px — despill напівпрозорих «вусів» у сірий (червоне/фіолетове ≥0.2 по хромі не чіпається). **Nano Banana 2.1 (2026-11-04):** модель малює справжню магенту (~254,7,250) і кидає тінь у темнішій hue-зсунутій магенті; RGB-відстань недооцінює покриття темного контуру поверх магенти (фіолетовий ореол/«вуса»), тому додано **pink-excess un-mix**: у смузі ≤40 px від ключа надлишок `min(r,b)-g` = частка фону `t` → `alpha=1-t`, колір `(c-t·bg)/(1-t)`; рожеві пікселі далі 6 px від ключа з `t≥0.25` = тінь (чорна, alpha ≤0.5); гейти — `cd<0.34` і `r≈b` (фіолетові акценти `#b58cff`, b≫r, не чіпаються). Залишок рожевого 3–8% → <0.4%. Тайли: зняття рамки-картки (модель копіює swatch-card з `ref_ground`) + cross-fade безшов + wrap-aware resize (seam-метрика 8.7 → 1.2). Resize — premultiplied. Напівпрозорі FX (дим, промінь сканера, сяйво) у спрайти НЕ запікаємо — змішуються з ключем і не відновлюються; правило `SOLO` у рамках sprite/actor/icon/ui (також забороняє тягнути пропи з якорів — ягоди з ref-листа «прилипали» до сокири). `repost` переганяє post.py по збережених raw без API.
- **Автоматика:** `node tools/gen-art.mjs sync` — `catalog.json` + живі id з `data.gd` (`parseDataGd`: food/torch/axe/pick/club/spear/sledge/vest/plate) → `art/manifest.json` (чиста ідемпотентна `buildManifest`; `subject` слідує шаблону, доки `subject === auto`, людська правка його заморожує; `status/notes` — людські; видалені def → `orphan`, ручні рядки `manual: true` — ніколи; підлоги/`grow_zone` → kind `tile`, стіни/кабелі/шипи — «1×1 сегмент ряду»; сировина/природа/якорі — без ERA); Node-тест падає, якщо маніфест розсинхронізований із каталогом (як `sync-catalog`). `gen` — лише `todo` (draft — `--only`/`--force`, approved — `--only`+`--force`), дефолт `--limit 12`. Кандидати → `art/out/` (gitignored) → `approve <id>@vN` → `godot/assets/gen/<kind>/<id>.png` (refs → `art/refs/`). Квота: Free Tier має `limit: 0` на ВСІ image-моделі — потрібен білінг проєкту ключа; `limit: 0` → батч зупиняється одразу, exit 3.
- **Ключ:** лише `.env.local` (0600, gitignored; `node tools/gen-art.mjs key`) або `$GEMINI_API_KEY`; маскується в усьому виводі, у meta не пишеться; `npm run lint` валить на `AIza…` у будь-якому трекнутому файлі. Exit: 2 = ключ недійсний/прострочений/перекритий старим `$GEMINI_API_KEY`, 3 = квота (Free Tier `limit: 0`, денна, довгий backoff — батч зупиняється одразу). CLI строгий (`util.parseArgs`): невідомий прапорець/`--limit 0`/неіснуючий `--only` id = помилка ДО платного виклику; Python+Pillow+numpy перевіряються ДО виклику; кожне оплачене зображення фіксується в маніфесті одразу (атомарний патч свіжого файла — паралельні правки не губляться).
- **Стан (2026-11-04):** усі 304 асети маніфесту `approved` (89 спрайтів · 12 тайлів · 3 актори · 198 іконок) + 2 якорі — ВСІ з `gemini-nano-banana-2.1` (перевірено по `*.meta.json`). Відбір кандидатів: 2 незалежні візуальні рецензенти на асет (технічна + fidelity лінзи) над композитом «трава/шахівниця» + піксельні метрики (`pink_residue_pct`, `partial_alpha_pct`, `seam_score`); ГОЧА: рецензенти позначають пласку торцеву грань сегмента-стіни як «cropped» — це хибний спрацьовувач (стіни 3 шт. вибрано вручну). Іконки з вузьким силуетом (ноги/хребет/лук) просять у notes «діагонально, велике, заповнює кадр».

Будбар: спрайти будівель (`ArtIcons.building`, обрізка `AtlasTexture`) + hover/press-твін. **Key-art (kind `key`, 16:9, без keying/resize, `assets/gen/key/`):** `key_spawn`/`key_death` — фон спавн-/смерть-екрана (`lifecycle.gd` `Chrome.add_backdrop` — повільний zoom-цикл ~26 с, `add_scrim`, `stagger_in`, `pop_button`).
