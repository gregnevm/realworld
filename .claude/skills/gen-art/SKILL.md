# gen-art — концептуальний арт-пайплайн

Скоуп пайплайна: `art/style.md` (стиль-гайд, додається до КОЖНОГО промпту) → `art/refs/*.png` (затверджені якорі стилю, ≤3 йдуть image-input у кожен запит) → `art/manifest.json` (що малювати; виводиться з `godot/content/catalog.json`) → `tools/gen-art.mjs` (API) → `tools/art/post.py` (Pillow+numpy: адаптивний keying фону → alpha, м'яка тінь, despill, trim, resize; тайли — зняття рамки + безшов; снеп до `art/palette.json` лише опційно `--palette`) → кандидати в `art/out/` (gitignored) → `approve` → `godot/assets/gen/<kind>/<id>.png` (комітиться).

## 0. Ключ (одноденний, від користувача)
- Користувач дає ключ у чаті → одразу: `printf %s '<KEY>' | node tools/gen-art.mjs key`. Це запише `.env.local` (0600, gitignored), перевірить `git check-ignore` і валідність ключа на API.
- НІКОЛИ не друкуй ключ (маскується `AIza…xxxx`), не клади його в код/коміт/PR/meta. Перед комітом `npm run lint` (secret-scan валить CI на `AIza…`).
- Exit 2 або «ключ недійсний або прострочений» → попроси новий ключ. НЕ ретрай.
- Exit 2 з «ПЕРЕКРИВАЄ .env.local» → у середовищі старий `$GEMINI_API_KEY`: `unset GEMINI_API_KEY`.
- Exit 3 або «квота 0 на Free Tier» → у проєкту ключа нема білінгу (на Free Tier усі image-моделі мають `limit: 0`). Попроси користувача ввімкнути білінг, ключ лишається той самий. Exit 3 «денна квота» → наступного дня.
- Прапорці строгі: друкарська помилка = помилка, а не тихий платний прогін.
- Ключ живе лише в контейнері сесії. Новій сесії потрібен новий `key`.

## 1. Цикл
1. `node tools/gen-art.mjs sync` (або `npm run sync`): підтягує нові def з каталогу і `data.gd`. Відредагований людиною `subject` і `status/notes` зберігаються.
2. **Якорі першими.** Якщо `art/refs/` порожній: `gen --only ref_world,ref_ground --n 3` → переглянь (Read PNG) → `approve ref_world@vN` (і ground). Без якорів стиль між батчами пливе.
3. Батч: `node tools/gen-art.mjs gen --kind icon --prefix res_ --limit 8 --n 2` (дефолтний ліміт 12 — захист від спалення квоти).
   Перед дорогим батчем можна `--dry`: друкує промпти без API.
4. Переглянь кандидати (`art/out/<kind>/<id>/vN.png`, Read). Відбраковуй, якщо:
   - фон не зник (магента лишилась) або обрізано об'єкт;
   - ракурс не top-down 3/4 (тайли — строго згори);
   - є текст/літери; палітра чи контур не як у refs;
   - предмет не той (перевір `label` у маніфесті).
   Рожевий відлив/обрізка після keying → спершу тюн `tools/art/post.py` + `node tools/gen-art.mjs repost [--only id]` (без API, без витрат), а не перегенерація.
   Дим/пара/сяйво (напівпрозоре поверх фону) → у спрайти не запікаємо, `notes: "no smoke plume — engine draws it"`.
5. Погане → додай рядок `notes` у маніфест (напр. `"notes": "ручка коротша, без металу"`) → `gen --only <id>`. `style.md` НЕ правиш заради одного асета.
6. Добре → `node tools/gen-art.mjs approve <id>@vN`. Approved не перегенеровується без `--only <id> --force`.
7. `node tools/gen-art.mjs status` → підсумок. Коміть `godot/assets/gen/**` + `art/manifest.json` (+ `art/refs/**` для якорів).

## 2. Kinds (рамка задана в `tools/art/lib.mjs` KINDS; не дублюй у subject)
| kind | що | розмір | фон |
|---|---|---|---|
| ref | лист-якір стилю | raw (~1024) | темний slate |
| sprite | будівлі (`bld_*`; стіни/кабелі/шипи — «1×1 сегмент ряду»), ресурсні ноди (`node_*`) | 128 | магента→alpha |
| actor | герой, рейдер, патрульний робот | 128 | магента→alpha |
| icon | ресурси `res_*`, предмети `item_*`, дослідження `rsch_*` | 128 | магента→alpha |
| tile | terrain `tile_*` (9 типів world_gen) + підлоги/грядка (`bld_floor`, `bld_*_floor`, `bld_grow_zone`) | 64 | безшовний |
| ui | HUD-піктограми (рядок вручну: `{"id":"ui_build","kind":"ui","subject":"…","status":"todo","manual":true}`, без `manual` sync позначить orphan) | 64 | магента→alpha |

Епоха (`eraOf(tier)`) додається автоматично з research-tier, тож неолітична сокира й plasteel-турель лишаються в одному світі.

## 3. Правила
- Оригінальний IP: жодних «in the style of <гра/студія/художник>», брендів, чужих персонажів.
- Обирай кандидат на тлі тайла трави або шахівниці, не на чорному: так видно залишки фону. Затверджені якорі: `ref_world`, `ref_ground`.
- Модель: дефолт `gemini-nano-banana-2.1` (до 10 референсів) — міграцію з `gemini-2.5-flash-image` виконано 2026-11-04: якорі й усі раніше затверджені асети перегенеровано, весь арт з однієї моделі. Старий id Google вимикає 2027-03-15. НЕ міняй модель посеред серії (зміна = перегенерація якорів і затвердженого). Pro — `--model gemini-3-pro-image`. `-preview` id вимкнені, CLI їх відхиляє.
- Підключення асетів у рендер Godot (`world_view.gd`/HUD) — окрема задача зі своїми тестами (R3/R11 view-шару). Цей скіл лише виробляє асети.
